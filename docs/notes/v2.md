# Version 2

## Fixes

1. A servo request is kept until `hitPuck()` actually runs.
2. Before every strike the servo is forced back to its rest angle.
3. If the puck stopped in the robot area:
   - the robot drives to its exact position;
   - after arriving, the servo strikes.
4. If the robot is already next to the puck:
   - the X/Y motors do not move;
   - the servo strikes immediately.
5. If the puck stays in place after the strike, another attempt is made after 850 ms.
6. The Python server also detects a puck that is not moving:
   - it searches near the last known position;
   - it does not pick a random red object instead.
7. The right side, close to the camera:
   - the ROI was extended to 0.98;
   - the puck size range is adjusted for perspective;
   - the color thresholds were widened for strong light or faded color.

## Running

Arduino: open `Arduino/AirHockeyMain/AirHockeyMain.ino`.

Python: stop the old server with Ctrl+C, open PowerShell in `Python_Live_Pair_Detector` and run:

```
py -m pip install -r requirements.txt
.\run_live_pair_server.bat
```

Status: `http://127.0.0.1:8001/camera/status`

New counter: `stationary_fallbacks`. It should increase when the puck stops.

## Expected ESP output

```
Stationary puck target X=... Y=...
Stationary puck reached - servo hit
```

or, when the robot is already next to the puck:

```
Puck already adjacent - servo hit without DC movement
```

## Calibration

The robot area is the first 42% of the image from the left:

```
ROBOT_AREA_EDGE_RATIO = 0.42f
```

If the robot goes for a puck that is too far, lower it to 0.35. If it does not reach a puck that stopped just outside the area, raise it to 0.46.
